#  IoT AI Safety Monitoring System

 # Problem Statement
Industrial environments face risks due to overheating, water leakage, and electrical faults.

# Proposed Solution
An IoT-based system using Arduino, Python, and Firebase to monitor real-time sensor data and detect anomalies.

# Technologies Used
- Arduino
- Python
- Firebase Realtime Database
- HTML Dashboard

 # System Flow
Sensors → Arduino → Python → Firebase → Dashboard

 # Features
- Real-time monitoring
- Alert detection (High temp, low water, high current)
- Cloud data storage using Firebase
- Live dashboard visualization
